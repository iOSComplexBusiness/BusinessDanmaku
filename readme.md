# BusinessDanmaku

## 简介

BusinessDanmaku 是一个私有 CocoaPods 库。

## 安装

在你的 `Podfile` 中添加：

```ruby
pod 'BusinessDanmaku', :git => 'https://github.com/iOSComplexBusiness/BusinessDanmaku.git'
```

然后运行：

```bash
pod install
```

## 使用

```objc
// 导入头文件
#import "BusinessDanmaku.h"
```

## 要求

- iOS 9.0+
- Xcode 10.0+
